# Karpathy-inspired Claude Code guidelines for academic research

A CLAUDE.md for AI research: data analysis, benchmarking, ML experiments,
and literature work. Research bugs don't crash; they produce plausible
numbers. These guidelines are built around that.

```bash
    curl -o CLAUDE.md https://raw.githubusercontent.com/Neclow/academic-research-claude-md/main/CLAUDE.md
```

Inspired by [multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills)
and Karpathy's [observations on notes on Claude coding](https://karpathy.github.io/2019/04/25/recipe/).

Not affiliated with either.
